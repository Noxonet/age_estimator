# تخمین‌گر سن با وبکم (آفلاین)

برنامه‌ای که وبکم رو باز می‌کنه، چهره رو تشخیص می‌ده و سن تقریبی رو زیر تصویر نشون می‌ده.
کاملاً **آفلاین** کار می‌کنه - بعد از نصب اولیه، به اینترنت نیازی نیست.

## محتویات پوشه

```
age_app/
├── age_estimator.py     ← فایل اصلی برنامه
├── requirements.txt     ← لیست کتابخانه‌های لازم
├── build_exe.bat         ← اسکریپت ساخت فایل exe
├── models/
│   ├── age_deploy.prototxt
│   └── age_net.caffemodel   ← مدل تخمین سن (~45 مگابایت)
└── fonts/
    └── Vazirmatn-Regular.ttf   ← فونت فارسی برای نمایش متن روی تصویر
```

## نحوه اجرا (روش سریع - با پایتون)

1. پایتون ۳.۹ به بالا رو از [python.org](https://www.python.org/downloads/) نصب کن (موقع نصب تیک "Add Python to PATH" رو بزن)
2. Command Prompt رو باز کن و برو داخل این پوشه:
   ```
   cd path\to\age_app
   ```
3. کتابخونه‌ها رو نصب کن:
   ```
   pip install -r requirements.txt
   ```
4. برنامه رو اجرا کن:
   ```
   python age_estimator.py
   ```
5. یه پنجره باز می‌شه، وبکمت روشن می‌شه و وقتی جلوش قرار بگیری دور صورتت یه کادر سبز می‌کشه و زیرش سن تقریبی رو می‌نویسه.
6. برای بستن برنامه، کلید `q` رو بزن.

## ساخت فایل exe مستقل (که پایتون لازم نداشته باشه)

اگه می‌خوای برنامه رو بدون نیاز به نصب پایتون روی هر ویندوزی اجرا کنی:

1. `pip install pyinstaller`
2. فایل `build_exe.bat` رو دوبار کلیک کن (یا در cmd اجرا کن)
3. بعد از چند دقیقه، فایل نهایی در `dist\AgeEstimator.exe` ساخته می‌شه
4. این فایل exe رو می‌تونی به تنهایی روی هر ویندوز دیگه‌ای هم اجرا کنی (نیازی به پایتون یا اینترنت نداره)

## نکات فنی

- **تشخیص چهره:** با Haar Cascade (بخشی از خود OpenCV، دانلود اضافه لازم نداره)
- **تخمین سن:** با یک شبکه CNN آماده (مدل Levi & Hassner، آموزش‌دیده روی دیتاست Adience) که سن رو در ۸ بازه تخمین می‌زنه: 0-2, 4-6, 8-12, 15-20, 25-32, 38-43, 48-53, 60-100
- چون این یه مسئله دسته‌بندی (classification) روی بازه‌هاست نه یه عدد دقیق، خروجی همیشه یک «بازه سنی» + درصد اطمینانه، نه یک عدد قطعی
- اگه خواستی دقت رو بالاتر ببری یا سن دقیق‌تر (نه بازه‌ای) بگیری، باید به سراغ مدل‌های جدیدتر (مثل مدل‌های InsightFace) بری که سنگین‌ترن و نصب پیچیده‌تری دارن

## تنظیمات قابل تغییر (داخل age_estimator.py)

- `CAM_INDEX` → اگه چند وبکم داری و می‌خوای یکی دیگه رو انتخاب کنی (0, 1, 2, ...)
- `DETECT_EVERY_N_FRAMES` → اگه روی سیستم ضعیف‌تر اجرا می‌کنی و می‌خوای سریع‌تر بشه، این رو به 2 یا 3 تغییر بده (تشخیص هر چند فریم یک‌بار انجام بشه)
